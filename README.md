# Bankasürans Takvim Yönetimi

Sunumdaki Vakıfbank, Ziraat Bankası ve Halkbank takvim maddelerinden hazırlanmış interaktif Gantt/takvim uygulaması.

## Çalıştırma

```bash
npm install
npm run dev
```

Codespaces / GitHub port açıldığında 5173 portunu açın.

## Özellikler
- Yeni satır ekleme / silme
- Banka, başlık, durum, sorumlu, not düzenleme
- Başlangıç ve bitiş tarihi girince takvim sütunlarının otomatik oluşması
- Tarih değişince Gantt barının otomatik uzayıp/kısalması
- JSON dışa/içe aktarma
- CSV dışa aktarma
- Tarayıcı localStorage kayıt
